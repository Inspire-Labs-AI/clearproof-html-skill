Two is not enough

A late duplicate SYN from an old connection can arrive. With two messages, the server opens a connection that nobody wants.

5 Words used here

ISN
Initial sequence number. Each side picks a random one per connection.
SYN
Synchronize. The flag that asks to start a connection.
MSL
Maximum segment lifetime. How long a stray packet can survive, often 2 minutes.

6 Closing takes four messages

Each side stops sending on its own. The server can still send data after the client sends FIN. The side that closes first waits 2 × MSL in TIME_WAIT, so late packets die before a new connection reuses the port.

  1. 1
    FIN

    The client has no more data

  2. 2
    ACK

    The server confirms; it may keep sending

  3. 3
    FIN

    The server is done too

  4. 4
    ACK

    The client confirms and waits in TIME_WAIT

7 Check yourself

Q1. Which message proves the client can receive?

The client can only acknowledge y if the SYN+ACK reached it.

Q2. Why does the ISN start at a random number?

So stray packets from an old connection, or a spoofer, cannot guess a valid sequence number.
